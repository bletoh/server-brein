# nb-api

Kleine helper: `nb-api METHOD /pad [json]` → NetBird-API op `https://netbird.benjaminhashi.nl/api` met het token uit `/srv/docker/netbird/api-token`. Gebruikt om proxy-services en policies te wijzigen. Sommige acties worden door de Claude-autoclassifier geblokkeerd → eigenaar doet ze in het dashboard.

Zie [[NetBird]], [[NetBird reverse proxy]], [[Claude Code sessies]].
